# 🤖 HRMS AI – Resume Screening & Chatbot System

An **AI-powered HRMS (Human Resource Management System)** that automatically screens resumes using ATS logic and allows HRs to **chat with resumes** using an intelligent AI chatbot.

Built using **Llama 3.1 / Llama 3.3**, **FastAPI**, and **Streamlit**.

---

## 🚀 Features

### 📄 Resume Screening (ATS Based)
- Upload **multiple PDF resumes**
- AI-powered **ATS score (0–100)**
- Skill matching & missing skills detection
- Experience & education extraction
- Resume ranking (Best → Worst)

### 🤖 Resume Chatbot
- Chat with any candidate’s resume
- Context-aware answers (no hallucination)
- Suggested HR questions
- Honest strengths & weaknesses analysis

### 🌐 API + UI
- FastAPI backend (REST APIs)
- Streamlit frontend (User-friendly UI)
- Pagination, filters & CSV export

---
